GIT COMMANDS USED IN THIS ASSIGNMENT
====================================

Step 1 - Local repository setup
-------------------------------
mkdir git-assignment
    Creates the project folder.
cd git-assignment
    Moves into the project folder.
git init -b main
    Initializes an empty Git repository with "main" as the default branch.
git status
    Shows which files are untracked, staged or modified.

Step 2 - Git workflow
---------------------
git add index.html about.html
    Stages both HTML files for the next commit.
git commit -m "Initial commit: add index.html and about.html"
    Records the initial state of the project (commit 1).
git diff
    Shows the unstaged changes made to index.html before committing.
git add index.html
    Stages the modified index.html.
git commit -m "Update index.html with intro paragraph"
    Records the modification as the second commit.
git branch feature
    Creates a new branch named "feature".
git branch
    Lists local branches; the current one is marked with *.
git switch feature
    Switches the working directory to the feature branch.
git add about.html
    Stages the footer change made to about.html.
git commit -m "Add footer to about.html (feature branch)"
    Commits the change on the feature branch.
git switch main
    Switches back to the main branch.
git merge --no-ff feature -m "Merge branch 'feature' into main"
    Merges feature into main; --no-ff forces a merge commit so the branch activity stays visible in history.
git log --oneline --graph --all --decorate
    Displays the compact commit history as a graph, including all branches.

Step 3 - .gitignore
-------------------
printf '*.log\ntemp/\n' > .gitignore
    Creates .gitignore that ignores all .log files and the temp/ folder.
git status --short
    Shows a short status; confirms debug.log and temp/ do not appear (they are ignored).
git add .gitignore
    Stages the .gitignore file.
git commit -m "Add .gitignore to ignore *.log and temp/"
    Commits the .gitignore file.

Step 4 - Undo operation
-----------------------
git add index.html
    Stages an extra (experimental) change to index.html.
git commit -m "Add experimental comment to index.html"
    Makes the additional commit that will be undone.
git log --oneline -3
    Shows the last three commits, before the undo.
git revert --no-edit HEAD
    Undoes the last commit by creating a new commit that reverses it (safe for shared history; nothing is rewritten).
git log --oneline -4
    Shows the history after the undo: the original commit and its revert are both present.
git show --stat HEAD
    Shows the revert commit and the file it changed.
tail -3 index.html
    Confirms the experimental comment is gone from the file.

Step 5 - GitHub integration
---------------------------
git add git_commands.txt
    Stages this documentation file.
git commit -m "Add git_commands.txt documenting all commands"
    Commits the documentation file.
gh repo create git-assignment --public --source=. --remote=origin
    Creates a public GitHub repository and adds it as remote "origin" (can also be done in the GitHub web UI plus "git remote add origin <url>").
git remote -v
    Verifies the remote URL that origin points to.
git push -u origin --all
    Pushes all local branches (main and feature) to GitHub and sets upstream tracking.
git log --oneline --graph --all --decorate
    Final check of the full history that is also visible on GitHub.
